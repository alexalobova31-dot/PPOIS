# Лабораторная работа №4, вариант 11

C++17. Обе части задания: In-place merge sort и Bogosort; обобщённый
неориентированный граф на структуре Вирта. Без Docker и конфигурационных файлов.

## Запуск

Нужны компилятор C++17 и make. Для тестов — UnitTest++ и желательно pkg-config,
как в соседних лабораторных. На текущем компьютере они уже установлены.

```sh
make run
make test
make clean
```

`make run` собирает и запускает `lab4`. `make test` собирает и запускает
`lab4_test`. `make clean` удаляет только результаты сборки и отчёты из `build/`.
Просто `make` собирает приложение без запуска. Интернет при сборке не нужен.

Параметры компилятора можно переопределять: `make CXX=clang++`.
Если pkg-config отсутствует, Makefile использует `-lUnitTest++`; нестандартные
пути можно передать через `CPPFLAGS`, `LDFLAGS`, `UNITTEST_CFLAGS`, `UNITTEST_LIBS`.

Дополнительные проверки:

```sh
make coverage
make sanitize
```

Для покрытия нужны Clang, llvm-cov и llvm-profdata. На macOS инструменты LLVM
находятся через xcrun. Пути переопределяются через `COVERAGE_CXX`, `LLVM_COV`,
`LLVM_PROFDATA`. HTML-отчёт: `build/coverage/index.html`.
Покрытие измеряется для Graph.h, Sorting.h, Student.h и Console.cpp, включая меню.
В отчёт не входят тесты, стандартная библиотека и main.cpp, который только
передаёт стандартные потоки в `run_console`.
`make sanitize` запускает тесты с AddressSanitizer и UndefinedBehaviorSanitizer.

## Сортировки

Обе функции принимают пару итераторов `[first, last)` и необязательный
компаратор, по умолчанию `std::less<>`. Работают с обычными массивами,
`std::array`, `std::vector`, встроенными типами и пользовательскими объектами.
Пустой диапазон допустим. Компаратор должен задавать строгий слабый порядок.

```cpp
int numbers[]{4, 1, 3, 2};
lab::in_place_merge_sort(std::begin(numbers), std::end(numbers));

std::vector<Student> students{{"Anna", 9}, {"Ivan", 6}};
lab::in_place_merge_sort(students.begin(), students.end());

std::mt19937 random(42);
lab::bogo_sort(students.begin(), students.end(), random, 100000);
```

In-place merge sort рекурсивно сортирует половины и сливает их с помощью
`std::rotate`, без вспомогательного массива. Устойчив: порядок равных элементов
сохраняется. В худшем случае O(n²) времени, O(log n) памяти для рекурсии.
Нужны изменяемые прямые итераторы; поддерживается также `std::list`.

Bogosort перемешивает элементы до упорядочивания. Требует изменяемых итераторов
произвольного доступа. Ожидаемое время для различных элементов O(n · n!).
Алгоритм неустойчив. По умолчанию допускается 100000 перемешиваний, затем
выбрасывается `std::runtime_error`; диапазон остаётся в последнем полученном
состоянии. Уже отсортированный диапазон принимается даже при лимите 0.
В меню размер vector для Bogosort ограничен восемью элементами; генератор
использует seed 42 для воспроизводимости демонстрации.

В `Student` сравнение по умолчанию идёт по оценке; свой компаратор позволяет
сортировать по имени или в обратном порядке. Стандартные `std::stable_sort`
и `std::is_sorted` используются в тестах для проверки результата.

## Граф

`Graph<T>` хранит значения типа T. Внутри — связанный список записей вершин;
у каждой вершины свой связанный список указателей на соседние вершины.
Это структура Вирта: для неориентированного ребра создаются две встречные
записи смежности. Внутренние узлы наружу не выдаются.

```cpp
Graph<std::string> graph;
auto first = graph.add_vertex("A");
auto second = graph.add_vertex("B");
graph.add_edge(first, second);
graph.value(first) = "Changed";
std::cout << graph;
```

ID вершины возвращается из `add_vertex`, начинается с 0 и не переиспользуется
после удаления или `clear`. Разные вершины могут хранить одинаковые значения.
Ребро представлено `std::pair<vertex_id, vertex_id>` с меньшим ID первым.
Петель и кратных рёбер нет. Порядок концов при обращении к ребру не важен.

Основные методы:

- `empty`, `clear`, `vertex_count`, `edge_count`;
- `has_vertex(id)`, `has_edge(first, second)`;
- `value(id)` с обычной и const-версиями;
- `vertex_degree(id)`, `edge_degree(first, second)`;
- `add_vertex(value)`, `add_edge(first, second)`;
- `remove_vertex(id)` и `remove_vertex(iterator)`;
- `remove_edge(first, second)` и `remove_edge(iterator)`.

Степень вершины — число её соседей. Степень ребра — число других рёбер с общим
концом: `degree(u) + degree(v) - 2`.
Проверки присутствия возвращают false для отсутствующих объектов. Доступ,
удаление и вычисление степени отсутствующего объекта выбрасывают
`std::out_of_range`; петли, повторные рёбра и чужие итераторы —
`std::invalid_argument`.

Конструктор копирования и оператор присваивания создают независимые вершины и
списки смежности, сохраняя ID. Присваивание сначала создаёт копию, поэтому ошибка
копирования T не меняет целевой граф. Ресурсы освобождаются автоматически.

Сравнения `==`, `!=`, `<`, `>`, `<=`, `>=` используют значения вершин в порядке
добавления, затем отсортированные пары их порядковых номеров. Численные ID и
порядок добавления рёбер не влияют на результат. Это сравнение представленных
последовательностей и связей, а не проверка изоморфизма графов. Для сравнений
нужны соответствующие операции над T.

## Итераторы

Диапазоны `vertices()`, `edges()`, `incident_edges(id)` и
`adjacent_vertices(id)` предоставляют `begin/end`, `cbegin/cend`, `rbegin/rend`,
`crbegin/crend`. Их пользовательские итераторы двунаправленные, поддерживают
`*`, `->`, `++`, `--`, постфиксные операции и стандартные алгоритмы STL.
Все диапазоны доступны и у const-графа.
Сам граф также поддерживает эти операции обхода по вершинам.

Дополнительный диапазон `adjacent_forward(id)` предоставляет только прямой
обход соседей: `begin/end`, `cbegin/cend`, `++`, без `--` и обратного обхода.

```cpp
auto neighbors = graph.adjacent_vertices(first);
for (auto it = neighbors.crbegin(); it != neighbors.crend(); ++it)
    std::cout << *it << ' ';

for (const auto& value : graph.adjacent_forward(first))
    std::cout << value << ' ';

auto edges = graph.edges();
graph.remove_edge(edges.begin());
```

Обычный итератор вершины разрешает менять T; const-итератор возвращает `const T&`.
Обычный итератор преобразуется в const-итератор, обратное преобразование запрещено.
Пары концов рёбер доступны только для чтения: изменение топологии выполняется
методами графа. Метод `id()` итератора вершины возвращает её ID.

Диапазоны создают снимок порядка обхода: указатели на существующие вершины либо
пары ID рёбер. Шаг итератора O(1); создание диапазона вершин O(V), рёбер O(V+E),
соседей и инцидентных рёбер O(V+degree) с учётом поиска вершины.
Дополнительная память пропорциональна длине диапазона. Сохраняйте диапазон
в переменную перед циклом, чтобы не создавать его повторно.

Любое успешное изменение структуры, очистка или присваивание другого графа
делает старые итераторы и диапазоны недействительными. Доступ через них
выбрасывает `std::logic_error`. Изменение значения T их не инвалидирует.
Удалять вершину можно по обычному или const-итератору диапазона `vertices()`;
ребро — по итератору `edges()` или `incident_edges(id)`.
За границами диапазона `*end`, `++end`, `--begin` выбрасывают исключения.
После уничтожения графа его итераторы использовать нельзя.

Текстовое представление графа строится через диапазоны и `std::for_each`.

## Меню и тесты

Меню позволяет выполнить обе сортировки, добавить, удалить и изменить вершины,
добавить и удалить рёбра, проверить присутствие и степени, просмотреть граф,
все виды обхода, удалить объекты по итератору, сохранить независимую копию,
сравнить граф с ней и очистить граф. Ввод построчный; некорректные значения
обрабатываются без завершения программы. Конец ввода завершает работу.
Данные существуют только в памяти процесса.

Тесты проверяют крайние случаи сортировки, устойчивость слияния, компараторы,
пользовательские объекты, лимит Bogosort, операции графа, глубокое копирование,
ошибку копирования, сравнения, все виды итераторов, их инвалидацию и команды меню.
Дополнительно случайные последовательности операций графа сверяются с моделью
на `std::set`. Фиксированные seed обеспечивают воспроизводимость тестов.
