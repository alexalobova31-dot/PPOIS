Detailed Description

Класс многочлена от одной переменной.

Представляет многочлен вида: a0 + a1*x + a2*x^2 + ... + an*x^n.

Коэффициенты хранятся в порядке возрастания степени: coefficients[0] - свободный член, coefficients[1] - коэффициент при x, coefficients[n] - коэффициент при x^n.
